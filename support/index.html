VECORD サポート

バックアップ、復元、通知について困ったときの確認方法をまとめています。

よくある質問

データはどこに保存されますか？
通常のデータは端末内のアプリ専用領域へ保存されます。ユーザー登録やクラウド同期は行いません。
バックアップに写真は含まれますか？
写真に関するメタデータは含まれますが、写真の実ファイルはJSONバックアップに含まれません。復元後は必要に応じて写真を再登録してください。
走行距離だけを設定した予定も通知されますか？
OSのローカル通知は、予定日が設定された次回整備が対象です。走行距離だけの予定は、アプリのホーム画面で残距離や超過状態を確認してください。
機種変更時にデータを移せますか？
旧端末でJSONバックアップを作成し、新端末のVECORDで復元できます。ただし写真の実ファイルは移行されません。

バックアップの作成方法

  1. VECORDの「設定」タブを開きます。
  2. 「バックアップを作成」を選びます。
  3. 注意事項を確認し、「作成して共有」を選びます。
  4. OSの共有シートから、信頼できる保存先を選びます。

重要: バックアップJSONは暗号化されません。車両情報や整備内容を含むため、保存先と共有相手を確認してください。

バックアップの復元方法

  1. VECORDの「設定」タブを開きます。
  2. 「バックアップから復元」を選びます。
  3. Document Pickerから対象のJSONファイルを選びます。
  4. 確認ダイアログの内容を読み、復元を実行します。

復元は既存データをバックアップ内容で置き換えます。現在のデータが必要な場合は、復元前に新しいバックアップを作成してください。破損したJSONや未対応versionは読み込まれません。

通知が届かない場合

  • VECORDの設定で「整備通知」がONになっているか確認する
  • 30日前、7日前、当日の必要な通知がONになっているか確認する
  • OS設定でVECORDの通知権限が許可されているか確認する
  • 対象の次回整備に予定日が設定されているか確認する
  • 予定日や通知時刻がすでに過去になっていないか確認する
  • 端末の省電力設定や集中モードを確認する

通知時刻はOSの判断により前後する場合があります。走行距離だけの予定はOS通知の対象外です。

お問い合わせ

解決しない場合は、お問い合わせフォームからご連絡ください。

お問い合わせフォームを開く

次の情報があると確認しやすくなります。

  • VECORDのVersionとBuild番号
  • iOSまたはAndroidの種類とOSバージョン
  • 行った操作と、期待した結果
  • 実際に表示されたエラーメッセージ
  • 問題が毎回起きるか、特定の条件だけで起きるか

入力しないでください: 氏名、住所、電話番号、車両の登録番号、ナンバープレート、位置情報、車台番号、保険情報、個人や車両を特定できる写真・バックアップファイル。返信を希望する場合のみ、メールアドレスを入力してください。
